# Frontend Design Prototypes

This directory contains standalone HTML files used as visual references while designing the Premily frontend.

## Purpose

These files help explore layout, visual hierarchy, and interface ideas before or during implementation in the Next.js application.

They are static HTML prototypes. They are not automatically connected to the backend, and their presence does not mean the corresponding functionality is implemented in the live application.

## Viewing the Prototypes

Open a prototype HTML file in a browser to inspect its design.

When implementing a design, transfer the relevant layout and styling into the appropriate Next.js page or reusable component under `apps/web/`.

Keep the production application's routing, data fetching, authentication, validation, and state management in the actual application code rather than treating a static prototype as a working feature.
